# CampusDelivery Mobile

App Android do CampusDelivery - um marketplace de alimentos do campus
Stack: React Native · Expo Go · TypeScript

## Pré-requisitos
- Node.js 20+ · pnpm · Expo Go · Git

## Rodando pela primeira vez
1. Clone: `git clone https://github.com/CampsuDelivery/campusdelivery-mobile/settings/branches`
2. Instale: `pnpm install`
3. Copie o env: `cp .env.example .env`
4. Rode: `pnpm start`
5. Escaneie o QR Code com Expo Go

## Comandos úteis
1. `pnpm start` | Inicia o servidor de desenvolvimento
2. `pnpm lint` | Roda o lint
3. `pnpm tsc --noEmit` | Checa os tipos TypeScript
